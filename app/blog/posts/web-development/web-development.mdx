# Lets get started!

### What is a website?

A website is a collection of web pages hosted on a server. A webpage is a document within a website that can be viewed through a browser.
**Imagine** a website as a human body. It has skeleten, muscles and the systems which makes the body function. Likewise
a website's skeleton or the basic structure is built using HTML. The muscle or so called the look of a website is built using css, those are the stylings, animations and anything related to design of the website. The functioning of a website is built using javascript like submitting the form, clearing the data etc..(we will not talk much about this as its not in the syllabus).

## What is HTML?

HTML (HyperText Markup Language) is the skeleton of your webpage. It defines the structure of your content using elements like headings, paragraphs, and images. HTML elements tell the browser on how to display a content. HTML elements are represented by HTML tags.

## The Structure of an HTML Page

Every HTML page starts with a basic structure. Here's an example:

```html {2,7-10}
<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is my first interactive web page.</p>
  </body>
</html>
```

## Styling with CSS

If HTML is the skeleton, **CSS** (Cascading Style Sheets) is the skin and clothing. It's what makes your website look beautiful. With CSS, you can change colors, fonts, layout, and even add animations!

Check out how we can style our HTML:
